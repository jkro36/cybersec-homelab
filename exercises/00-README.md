## How Each Exercise Is Structured

Every exercise README contains these sections in this order:

1. **Goal** — what the exercise demonstrates and why it matters
2. **Environment** — which VMs, IPs, snapshot taken
3. **Background** — the concept explained in plain English
4. **Prerequisites** — what must be true before starting
5. **Steps** — every command with flags explained, output shown
6. **Findings** — what was actually achieved, in a table
7. **Detection Analysis** — what each tool logged, what was missed
8. **Detection Rules Written** — Sigma, Suricata, Kibana KQL
9. **MITRE ATT&CK Mapping** — tactic, technique, sub-technique
10. **Skills Demonstrated** — bulleted list for resume reference
11. **Remediation** — what defends against this in a real environment
12. **References** — ATT&CK links, research, tool documentation
13. **IOCs** — sanitized indicators from the exercise
